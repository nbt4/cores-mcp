# Cores knowledge base

This directory contains non-sensitive internal context that may be returned to connected MCP clients.

Add Markdown, text, CSV or JSON files such as:

- equipment strategy and preferred platforms;
- purchasing principles and approval thresholds;
- approved manufacturers and supplier guidance;
- operational standards and terminology;
- lessons learned that should influence future decisions.

Do not store credentials, personal data, customer secrets or unrestricted document exports here. Document contents are sent to the connected AI provider when a user asks the client to read them.
